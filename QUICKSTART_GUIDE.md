## 🎮 How to Use

### 1. **Open Browser**
```
http://localhost:3000
```

### 2. **Click Start Menu** (≡ button in bottom-left)
- Search for any app by typing
- Click app icon to launch

### 3. **Manage Windows**
- **Drag:** Click title bar and move
- **Minimize:** Click ⊞ button
- **Maximize:** Click ⬜ button
- **Close:** Click X button
- **Multi-window:** Open multiple apps at once

### 4. **Explore Features**
Try each app:
- **AI Studio:** Send messages
- **Documents:** Type and format text
- **Spreadsheet:** Edit cells, add rows
- **Dashboard:** Watch metrics update live
- **Calendar:** Navigate months
- **Tasks:** Add priorities
- **And more!**

## 🔧 Troubleshooting

**App won't load?**
- Hard refresh: Ctrl+Shift+R
- Check browser console (F12)

**Performance lag?**
- Close unused windows
- Minimize background apps
- Check DevTools performance tab

**Dev server down?**
```bash
npm run dev
```
