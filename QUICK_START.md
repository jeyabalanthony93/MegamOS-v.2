## 🎯 How to Use Each App

### **1. AI Studio** 🤖
```
1. Launch app
2. Choose prompt template OR type your request
3. Click Send or press Enter
4. Get AI response
5. View history of all conversations
```

### **2. Code Studio** 💻
```
1. Launch app
2. Select programming language
3. Write code
4. Download as file or Copy to clipboard
5. Save your work
```

### **3. Mail Pro** 📧
```
1. Launch app
2. View inbox OR click "Bulk Send"
3. For bulk send:
   - Write subject
   - Write message
   - Set send time (optional)
   - Click "Schedule & Send"
4. Done! Emails queued
```

### **4. Calendar Pro** 📅
```
1. Launch app
2. Navigate months (< >)
3. Click date to view events
4. Add event:
   - Enter date
   - Enter title
   - Set time
   - Click "Add Event"
5. Event appears on calendar
```

### **5. Database Pro** 🗄️
```
1. Launch app
2. Select database type
3. Write SQL query
4. Click "Execute"
5. View results in table
6. Export SQL if needed
```

### **6. Dashboard Pro** 📊
```
1. Launch app
2. View stat cards
3. Toggle Chart/Card view
4. Click "Export CSV" for data
5. View analytics
```

## 🐛 Troubleshooting

### **Blank Screen**
```
→ Refresh page (F5)
→ Clear browser cache
→ Restart dev server
```

### **App Won't Load**
```
→ Check browser console
→ Ensure npm packages installed
→ Restart dev server: npm run dev
```

```
→ Close unused windows
→ Clear browser cache
→ Restart browser
```
