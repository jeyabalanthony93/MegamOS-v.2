## 🚀 Getting Started

### **Launch an Application**
1. Click the **🚀 Start Menu** button (bottom-left)
2. Search for any application
3. Click to launch (opens in a new window)
4. Use the window controls to:
   - **Drag** to move windows
   - **Minimize** (top-right button)
   - **Close** (X button)

### **Quick Actions**
- **Search**: Filter apps by name
- **Taskbar**: Click minimized apps to restore
- **System Tray**: Access theme, notifications, time
- **Multiple Windows**: Open as many apps as needed

## 📱 Application Examples

### **AI Studio Workflow**
```
1. Click "AI Studio" from Start Menu
2. Choose a prompt template (Write Article, Generate Code, etc.)
3. Or type your custom prompt
4. Click Send or press Enter
5. Get instant AI-powered responses
6. Export conversation history
```

### **Code Editor Workflow**
```
1. Launch "Code Studio"
2. Select programming language
3. Write code in the editor
4. Real-time character/line counting
5. Download as file or copy to clipboard
6. Save your work
```

### **Mail Pro Workflow**
```
1. Open "Mail Pro"
2. Either:
   a. View existing emails, or
   b. Click "Bulk Send" for mass messaging
3. For bulk send:
   - Write subject and message
   - Set schedule time (optional)
   - Choose recipients
   - Click "Schedule & Send"
4. Track delivery status
```

### **Calendar Pro Workflow**
```
1. Launch "Calendar Pro"
2. Navigate months with arrow buttons
3. Click dates with events to view details
4. Add new events:
   - Select date
   - Enter title
   - Set time
   - Click "Add Event"
5. Events appear on calendar
```

### **Database Pro Workflow**
```
1. Open "Database Pro"
2. Select database type (PostgreSQL, MongoDB, etc.)
3. Write SQL query
4. Click "Execute" to run
5. View results in table format
6. Export results as CSV or SQL
```

## 🐛 Troubleshooting

### **Blank Screen**
- Refresh the page (F5)
- Clear browser cache
- Restart dev server

### **App Won't Load**
- Check browser console for errors
- Ensure all dependencies installed: `npm install`
- Restart dev server

### **Performance Issues**
- Close unused windows
- Clear notifications
- Refresh the page

### **Keyboard Input Not Working**
- Click inside text area first
- Check if window is focused
- Try maximizing the window
