## 🚀 How to Use

### Start the Application
```bash
cd c:\Users\USER\OneDrive\Documents\megamos\MegamOS-v.2
npm run dev
```
Then visit: **http://localhost:3000/**

### On the Screen You'll See
1. **Beautiful gradient background** with animated particles
2. **🚀 Button** (Start Menu) in bottom-left
3. **Taskbar** at the bottom with theme toggle
4. **Welcome message** when no windows are open

### Launch Applications
1. Click the **🚀 Start Menu** button
2. Search for an app or click one directly
3. New **draggable window** opens
4. Use the app normally
5. Click **−** to minimize or **✕** to close

### Features to Try
- **Drag windows** by title bar
- **Minimize/Close** apps with buttons
- **Toggle dark/light mode** with sun/moon icon
- **Search apps** in start menu
- **Check time** in taskbar (updates every second)
- **Open multiple apps** at once

## ❓ Troubleshooting

### **Blank White Screen?**
1. Check if dev server is running
2. Open http://localhost:3000/ in browser
3. Press F12 and check console for errors
4. Try: `npm run dev` again

### **Applications Not Showing?**
1. Click the 🚀 (Start Menu) button
2. Applications list should appear
3. Click on any app to launch
4. New window opens with app

### **Animations Not Smooth?**
1. Check browser's GPU acceleration is on
2. Update your browser to latest version
3. Close background applications
4. Try in a different browser

### **Build Issues?**
```bash
rm -rf node_modules
rm package-lock.json
npm install
npm run dev
```
