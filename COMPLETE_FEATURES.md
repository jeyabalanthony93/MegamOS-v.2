## 🎓 Getting Started Guide

### **Installation**
```bash
git clone https://github.com/jeyabalanthony93/MegamOS-v.2.git
cd MegamOS-v.2
npm install
npm run dev
```

### **Access**
- Local: http://localhost:3000/
- Network: http://[YOUR-IP]:3000/

### **Launch Apps**
1. Click the 🚀 button
2. Type to search
3. Click to launch
4. Drag to move, click X to close
